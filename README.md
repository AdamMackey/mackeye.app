# mackeye.app

The website for MackEye Apps: small apps that each fix one thing, properly. Plain HTML and CSS, served by GitHub Pages at <https://mackeye.app>.

The apps have their own repos:

- [Desktop Please](https://github.com/AdamMackey/desktop-please)
- [Hold Please](https://github.com/AdamMackey/hold-please)
- [Simple Battery](https://github.com/AdamMackey/simple-battery)
- [Titleous](https://github.com/AdamMackey/titleous)
- [Terminous](https://github.com/AdamMackey/terminous)
- [Bangarang](https://github.com/AdamMackey/bangarang)
- Meterous and Pulseous: <https://meterous.app> and <https://pulseous.app>
