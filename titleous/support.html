Support

Setting up Titleous, and answers to the usual questions.

Setting up

Safari

  1. Get Titleous from the Mac App Store. It's free.
  2. Open Titleous once from your Applications folder.
  3. In Safari, choose Settings → Extensions and tick Titleous.
  4. Allow it on claude.ai when Safari asks.
  5. That's it. Switch chats as usual, and within a second the tab takes the name of the chat you're in.

Chrome, Edge and Firefox

  1. Install Violentmonkey or Tampermonkey.
  2. Open titleous.user.js and confirm the install. It's the same code as the Safari extension, free on GitHub.
  3. Reload any claude.ai tabs you already have open.

Questions

What does Titleous change?

Only the title of your claude.ai tabs. claude.ai switches chats without loading a new page, so a tab can keep the name of the chat it first opened until you refresh it. Titleous sets the title to the chat you're actually in, however you switched: the sidebar, search, the keyboard, or Back and Forward.

Why does a tab say just "Claude"?

That tab isn't on a chat. It's on claude.ai's home page, a project or settings, so there's no chat name to show, and Titleous puts back "Claude" rather than leave the last chat's name up. A new chat takes its name as soon as claude.ai gives it one.

Does it work with the sidebar closed?

Yes. With the sidebar closed, it reads the name from the chat's own header instead.

What about tabs Safari reopens after a restart?

Safari reopens tabs before its extensions are ready, so Titleous adds itself to each of those tabs the moment you switch to it. No reload needed.

It isn't renaming my tabs

Check that Titleous is ticked in Safari → Settings → Extensions, and that it's allowed on claude.ai: click Titleous in that list, then Edit Websites, and set claude.ai to Allow. Then switch to a claude.ai tab.

Can Titleous read my chats?

It reads chat names only: the ones claude.ai lists in its sidebar, and the name on the chat's header. It never reads your messages, and it has no access to any other website. It makes no network requests and stores nothing, so nothing it sees leaves your computer. The privacy policy has the detail.

Something's wrong. How do I report it?

Email support@mackeye.app with your macOS and Safari versions and what you saw, or open an issue on GitHub. Titleous keeps no logs and has nothing in it that identifies you. If you use Safari's Web Inspector, typing document.documentElement.dataset.titleous in a claude.ai tab's console shows what Titleous last found there; paste that line in too.
